# KidWiz Brand Assets

These assets were copied from the owner-provided KidWiz design archive for the
local KidWiz prototype rebrand.

- `kidwiz-logo.svg` and `kidwiz-logo-large.png`: KidWiz logo artwork.
- `kidwiz-bot.png`: KidWiz robot tutor artwork used for the Learning Studio and
  public hero direction.
- `/favicon.svg`: simplified KidWiz atom mark used as the browser favicon.

Do not copy old `.env` files, raw backup archives, or unrelated stock packs into
the app. If additional archive illustration packs are used later, confirm their
license and attribution requirements before committing them.
